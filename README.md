# Проект виджет банковских операций клиента


## Описание проекта 
Это веб-приложение на Python по созданию виджета для банковских операций клиента


## Описание функций
- Создана функция mask_account_card для маскировки банковской карты и счета
  * принимает на вход текстовые данные карты или счета и выводит замаскировнный номер карты/счета
- Создана функция filter_by_state для фильтрации данных словарей по ключу
  * принимает на вход список словарей в формате строки и целого цикла и возвращает список словарей в формате строки и целого числа отфильтрованных по ключу  
- Создана функция get_date для изменения формата даты
  * принимает на вход строку с датой и возвращает строку с измененным типом формата даты
- Создана функция sort_by_date для сортировки даты по ключу
  * Принимает на вход список словарей в формате строки и целого цикла и возвращает список словарей в формате строки и целого числа отсортированные по ключу( ключом является параметр реверса) взависимости от того какая нужна сортировка по убиванию или возврастанию 
- Создана функция filter_by_currency для фильтрации списка словарей по заданной валюте
  * Принимает на вход список словарей, представляющих транзакции и возвращает итератор, который поочередно выдает транзакции, где валюта операции соответствует заданной
- Создана функция transaction_descriptions для описания каждой транзакции по очереди
  * Принимает на вход список словарей с транзакциями и возвращает описание каждой операции по очереди
- Создана функция card_number_generator для генерации диапазона номеров карт
  * Генератор может сгенерировать номера банковских карт в определенном диапазоне, принимает на вход начальное и конечное значения для генерации диапазона номеров. 
- Создан декоратор log
  - Декоратор выводит дату и время начала и конца операции функции, результат и ошибки если они есть
- Создана функция read_json_file
  - Функция принимает на вход путь к JSON файлу и позволяет его читать, так же выкидывает исключение если файл не найдет и JSON битый
- Создана функция currency_conversion
  - Функция для конвертации валют (USD и EUR) в рубли, принимает на вход список словарей с транзакциями и возвращает сумму в рублях типа float, обмен согласно текущему курсу валют
- Добавлено логирование для функций: get_mask_card_number и get_mask_account, которое включает в себя логи запуска, предупреждений, успешной отработки, а так же ошибок если они были
- Создана функция read_csv_file
  - Функция для считывания финансовых операций из CSV принимает путь к файлу CSV в качестве аргумента.
  - Функция для считывания финансовых операций из CSV выдает список словарей с транзакциями.
- Создана функция read_excel_file
  - Функция для считывания финансовых операций из Excel принимает путь к файлу Excel в качестве аргумента.
  - Функция для считывания финансовых операций из Excel выдает список словарей с транзакциями.
